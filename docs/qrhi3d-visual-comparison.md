# DVD 原型画面对照

> 当前项目使用 Qt 6.12.0；本文原有测试与性能数据保留实测时的 Qt 6.10.3 版本标注。

2026-10-16；Qt 6.10.3，D3D11，1280×720 像素，DPR 1，4x MSAA。
旧版直接使用未修改的生产 QML；新版使用从同一四个 mesh 导出的 GLB。两者使用同一合成封面和 globalIndex 500，正视镜头、聚焦距离 0.2，打开时 spine/front 各 -90°。


已检查：盒体尺寸、铰链与盘面位置，FRONT/BACK 与 TOP↑ 的 UV 方向，材质子集和淡黄色光盘环。比较发现并修复两处导出差异（UV 的 V 方向、Qt #AARRGGBB 的 alpha/线性色转换）和聚焦 pivot 横向偏移。原型保留正确的前景位置和朝向。

当前差异：旧版 HDR/IBL/AO 使白壳和封面更亮且有环境反射，新版为基础 GGX+环境/方向光和纯色背景；阴影/环境贴图尚未复制。旧版作品详情/爱心/编辑/删除覆盖层属于生产 UI，独立 demo 使用侧栏标题与操作。书架可见窗口及动画时序各自驱动，背景邻片边缘可能不同。当时的画面对照未进行像素等价验收。

历史测试截图、交互动画与合成输入数据已清理。复现命令与截图选项见 [demo README](../apps/render3d_demo/README.md)。

2026-10-16 后续增量已加入 HDR/IBL/AO/阴影，见 [新光照记录](qrhi3d-lighting.md)。本页保留基础光照版本当时发现的问题，不代表当前默认画面。
