2026-10-24 首页封面预算收紧：CPU 封面缓存与 GPU 源纹理预算均从 512 MiB 降至 64 MiB，沿用按投影尺寸加载封面的策略。预算不包含 HDR 与渲染目标，也不保证场景仍引用的 CPU 图片会随缓存淘汰立即释放。下文 512 MiB 为此前实现记录。

2026-10-24 小封面内存调整：移除首页封面请求尺寸的投影高度 ×4 和最低 2048 像素限制。改为按投影高度与 DPR 直接请求，按 256 像素向上分档，范围为 256～4096；保留 mipmap、8 次各向异性过滤和小图不放大。下面的高清封面策略与验证记录为此前实现。
