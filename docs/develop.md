# DarkEye C++ / Qt 版本概览

DarkEye 是一个 Windows 本地媒体资料库。当前代码库是独立的 **C++20 / Qt 6** 桌面程序，
不依赖 Python 运行时或 Python 绑定层。它以本地 SQLite 数据库管理作品与人物资料，并提供
作品整理、元数据采集、关系图、书架浏览、统计、备份和本地 HTTP 联动能力。

## 当前已实现的功能

| 区域 | 已实现能力 |
| --- | --- |
| 作品库 | 作品列表、搜索、排序、标签和厂牌等条件筛选；查看、编辑和新增作品；本地视频路径同步。 |
| 人物资料 | 女演员和男演员的列表、详情、编辑、作品关联与头像资料管理。 |
| 管理 | 作品录入、标签/厂牌/系列/制作商管理、批量状态操作、汇总查询、软删除与回收站。 |
| 采集 | 本地采集队列、字段选择、暂停/取消和失败恢复；通过外部 Collector 获取作品、人物、图片和热门人物数据。 |
| 关系图 | 从本地数据库生成作品和人物关系；支持全图、中心节点邻域、收藏筛选、节点图片及 GPU 渲染。 |
| 浏览与分析 | 仪表盘、作品书架、剧照浏览、统计和个人数据记录页面。 |
| 设置与维护 | 主题与主色、快捷键、视频目录和播放器、NFO 导入、翻译服务、数据库维护、本地/WebDAV 备份与恢复。 |
| 本地联动 | 内置仅本机监听的 HTTP API（默认 `127.0.0.1:56789`），供浏览器扩展推送采集请求。 |

“暗黑界”“通知”等入口也已在主窗口中注册；其中通知页用于显示采集队列状态。功能是否可用取决于
相应的本地数据、外部 Collector 或浏览器扩展是否已经配置。

## 运行时组成

```text
Darkeye.exe
├─ Qt Widgets / Qt Quick：桌面界面、主题和通用组件
├─ SQLite：公共资料库与私有资料库
├─ 本地 HTTP API：浏览器扩展及本机工具联动
├─ CollectorClient：调用可选的外部信息补充器（默认 127.0.0.1:56790）
├─ GraphView：关系图的物理仿真与 QRhi 渲染
└─ resources/ 与 data/：资源、配置、数据库、图片、日志和用户数据
```

应用启动后会创建运行目录、初始化数据库、应用保存的主题、构造主窗口，并在事件循环开始后启动
本地 API、按设置启动外部 Collector、检查更新；如已配置，也可启动本地 `llama-server` 用于翻译。

## 代码布局

| 目录 | 责任 |
| --- | --- |
| `apps/desktop/` | `Darkeye` 可执行程序、应用生命周期和主窗口导航。 |
| `libs/core/` | 领域模型、资源与日志、HTTP API、采集客户端和任务调度。 |
| `libs/database/` | SQLite 连接、建库/维护、备份、WebDAV、CSV 及领域仓储。 |
| `libs/services/` | 采集结果持久化、人物同步、图片、翻译、更新、视频库和批处理服务。 |
| `libs/graph/` | 关系数据读取、图存储和图会话。 |
| `libs/graph_view/` | 力导向物理、MSDF 文字、QRhi 图形渲染与视图适配。 |
| `libs/darkeye_ui/` | 主题、布局和可复用的视觉组件。 |
| `libs/ui/` | 业务页面、编辑器、对话框和管理界面。 |
| `resources/` | Qt 资源、默认配置、SQL、图标和随程序发布的资源。 |
| `data/` | 可选的初始/发布数据；是否安装由 CMake 预设决定。 |

## 开发约定

- 新功能应优先放入已有的 `libs/*` 分层，并由 `apps/desktop/` 负责组合，而不是把业务逻辑塞入主窗口。
- 使用 Qt 信号/槽连接页面与异步服务；耗时网络和采集操作不得阻塞 GUI 线程。
- 数据库访问通过 `DatabaseManager`、`SqliteConnection` 和领域仓储完成；公库与私库由 `settings::Paths` 提供路径。
- 关系图代码分为数据层 `libs/graph/` 与渲染层 `libs/graph_view/`；页面不直接操作底层 GPU 状态。
- C++ 采用 C++20。MSVC 构建启用 `/W4`、`/permissive-` 和 UTF-8 源文件编码。

构建、测试、Visual Studio/VS Code 调试及发布目录生成，请阅读[开发准备](development.md)。
更细的模块依赖与数据流请阅读[整体架构](architecture.md)。
